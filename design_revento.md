# Design System — Revento

Дизайн-система лендинга: тёплый, «редакционный» стиль на стыке SaaS и модной верстки — тёмно-синий + Fraunces-курсив создают ощущение бутикового продукта, а не типового IT-лендинга.

---

## 1. Цвета

| Токен | Значение | Назначение |
|---|---|---|
| `--ink` | `#1B2340` | Основной текст, тёмный фон (hero, footer, тарифная карточка) |
| `--ink-soft` | `#4A5178` | Вторичный текст, описания |
| `--paper` | `#F5F6FA` | Фон страницы (светлый, слегка холодный) |
| `--paper-alt` | `#FFFFFF` | Фон карточек, alt-секций |
| `--coral` | `#FF6B54` | Акцент №1 — CTA, ссылки, иконки, выделения |
| `--coral-dark` | `#E5523C` | Hover-состояние акцента, тёмный коралл в бейджах |
| `--gold` | `#E8A33D` | Акцент №2 (второстепенный, для разнообразия иконок) |
| `--line` | `#DFE2EC` | Тонкие границы, разделители |
| `--line-strong` | `#C6CBDD` | Границы при hover / outline-кнопки |

Дополнительные фоновые оттенки для иконок (используются inline, не вынесены в токены):
- `#FFF1EE` — коралловая подложка иконок
- `#FDF2E0` — золотая подложка иконок
- `#ECEDF6` — нейтральная (ink) подложка иконок
- `#FFF6F4` — hover-фон для тегов категорий

**Hero-градиент:** `radial-gradient(120% 140% at 15% 0%, #323A66 0%, #1B2340 55%, #161B34 100%)` — тёмно-синий радиальный переход, светлее в левом верхнем углу.

---

## 2. Типографика

Три шрифта, у каждого своя роль:

| Роль | Шрифт | Где используется |
|---|---|---|
| Заголовки / display | `Fraunces` (serif, вариативный) | H1, H2, названия карточек, логотип, цена в тарифе |
| Основной текст | `Manrope` (sans-serif) | Body-текст, кнопки, навигация |
| Технический / акцентный | `IBM Plex Mono` | Бейджи, «эйброу»-подписи, метки шагов, метаданные тикетов |

Подключение:
```css
@import url('https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@0,9..144,400;0,9..144,600;0,9..144,700;1,9..144,500&family=Manrope:wght@400;500;600;700;800&family=IBM+Plex+Mono:wght@500;600&display=swap');
```

**Характер заголовков:** Fraunces используется с курсивом (`font-style: italic`) для акцентных слов внутри H1 — это фирменная деталь бренда, не просто жирный текст, а именно вкрапление курсивного serif на фоне обычного текста.

**Шкала размеров:**
- H1 (hero): `48px` / `600` / `line-height 1.15` / `letter-spacing -0.5px`
- H2 (section-title): `34px` / `600` / `letter-spacing -0.4px`
- H2 (problem-block): `30px` / `600`
- Карточки (feature-card h3): `19px` / `600`
- Карточки (step h3): `17px` / `600`
- Body / description: `16–17px` / `line-height 1.65–1.75`
- Мелкий текст (meta, теги): `12–14.5px`, часто в моноширинном шрифте с `text-transform: uppercase` и `letter-spacing`

---

## 3. Сетка и отступы

- **Контейнер:** `max-width: 1120px`, `padding: 0 24px`, центрирован.
- **Секция:** вертикальный паддинг `96px 0` (на мобильных — `64px 0`).
- **Радиусы скругления:** мелкие элементы `10–14px`, карточки `16–18px`, крупные блоки (тариф) `22px`, теги/бейджи — `pill` (`20–24px` или `50%` для точек).
- **Тени:** мягкие, окрашенные под фон блока — например, `0 6px 18px rgba(255, 107, 84, .28)` у коралловой кнопки, `0 20px 40px rgba(10, 12, 30, .35)` у карточек-тикетов на тёмном hero.

---

## 4. Компоненты

### Кнопки (`.btn`)
- Базовые параметры: `padding: 12px 26px`, `border-radius: 10px`, `font-weight: 700`, `font-size: 14.5px`.
- **Primary** — заливка `--coral`, тень в цвет, при hover темнеет до `--coral-dark` и поднимается на `-2px`.
- **Outline** — прозрачный фон, граница `--line-strong`, при hover граница темнеет до `--ink`.
- **Ghost-light** (для тёмного hero) — полупрозрачная белая заливка `rgba(255,255,255,.08)`.
- Модификатор `.btn-lg` — увеличенный паддинг для hero-CTA.
- Все переходы — `.18s` по кастомному easing `cubic-bezier(.22, .61, .36, 1)`.

### Header
- Sticky, `backdrop-filter: blur(10px)`, полупрозрачный белый фон `rgba(255,255,255,.88)`.
- Логотип — Fraunces italic bold, часть слова окрашена в коралл через `<span>`.
- Навигация — подчёркивание акцентом при hover (анимация `width` от 0 до 100%).

### Hero
- Тёмный радиальный градиент на всю секцию, белый текст.
- Bagde с точкой-индикатором (`.hero-badge .dot`) — моноширинный текст, коралловая точка.
- Фирменный визуальный приём — «стопка тикетов» (`.ticket`): три карточки-подсказки, повёрнутые под разными углами, с лёгкой бесконечной анимацией плавания (`floaty`, 6s, вертикальное покачивание ±14px) и двумя «дырками» по бокам (имитация билета/квитанции).

### Карточки (шаги, фичи, категории)
- Единый паттерн: белая заливка, тонкая граница `--line`, при hover — лёгкий подъём (`translateY(-5..-6px)`) и увеличение тени.
- Иконки — квадрат с скруглением 10–14px, три цветовых варианта подложки (coral / gold / ink).
- Шаги дополнительно имеют моно-бейдж номера шага на светлой коралловой подложке.

### Теги категорий
- Pill-форма, при hover — граница и фон окрашиваются в коралл, иконка внутри слегка поворачивается и увеличивается (`scale(1.12) rotate(-4deg)`).

### Тарифная карточка
- Тёмная (`--ink`) карточка на светлом фоне секции — визуальный контраст, «выделенный» тариф.
- Декоративное радиальное пятно коралла в углу (`::before`).
- Список фич с чекмарками в коралле, разделители — полупрозрачные белые линии.

### Footer
- Тёмный фон, центрированный контент, логотип Fraunces italic, приглушённый серый текст.

## 5. Анимация и интерактивность

- **Reveal-on-scroll:** элементы с `[data-reveal]` появляются снизу вверх (`translateY(22px) → 0`, `opacity 0 → 1`), длительность `.7s`, с кастомными задержками через `--d`.
- **Плавающие тикеты в hero:** `@keyframes floaty`, у каждой карточки свой угол наклона и задержка анимации.
- **Уважение к `prefers-reduced-motion`:** анимации и smooth-scroll отключаются для пользователей с настройкой сокращённого движения.
- Единый easing для всех transition: `cubic-bezier(.22, .61, .36, 1)` — мягкий, слегка пружинящий выход.

---

## 6. Адаптивность

Брейкпоинты: `900px` и `768px`.

- **≤900px:** hero-сетка и problem-блок становятся одноколоночными, шаги — 2 колонки, фичи — 1 колонка.
- **≤768px:** навигация в шапке скрывается, уменьшаются заголовки (H1 → 32px, section-title → 26px), кнопки hero складываются в столбец, тикеты уменьшаются в ширину.

---

## 7. Общие принципы

1. **Контраст тёмного и светлого** — тёмно-синие блоки (hero, footer, тарифная карточка) чередуются со светлыми секциями, задают ритм страницы.
2. **Serif-курсив как подпись бренда** — Fraunces italic в логотипе и акцентных словах H1 отличает продукт от типовых sans-only SaaS-лендингов.
3. **Моноширинный шрифт = «техническая» деталь** — используется точечно (бейджи, метки, эйброу), создаёт ощущение точности и продуманности, не в ущерб читаемости основного текста.
4. **Один акцентный цвет, а не радуга** — коралл используется последовательно для всех интерактивных и «важных» элементов; золото — только как второй вариант подложки иконок, для лёгкого разнообразия.
5. **Сдержанная моушн-дизайн** — анимации короткие, физичные (лёгкий подъём, плавание), не отвлекают от контента.
6. **Доступность:** видимый `focus-visible` outline в цвет акцента, поддержка `prefers-reduced-motion`.
